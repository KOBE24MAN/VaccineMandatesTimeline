MANDEVAL CLIENT DEMO

Requirements
- Windows 10 or Windows 11
- An internet connection
- A modern web browser

Start the demo
1. Double-click Start-Demo.bat.
2. Wait while the launcher checks the hosted service.
3. The demo opens in your default browser when the service is healthy.

Troubleshooting
- If the launcher reports that the URL is not configured, request the final deployment package from the project team.
- If the launcher reports that the service is unavailable, confirm your internet connection and try again.
- If the problem continues, send the exact English error message to the project team.

This package does not install software and does not require Azure or Docker credentials.
