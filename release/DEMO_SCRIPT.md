# Demo Script

1. Open the public demo URL and confirm the timeline loads without a login prompt.
2. Point out that the header reports 279 total mandates.
3. Use the jurisdiction controls to isolate Western Australia, then restore all jurisdictions.
4. Toggle a mandate type and a target category to demonstrate combined filtering.
5. Search for `health` and open one search result.
6. Select a timeline bar and show the full detail panel.
7. Enable a notable event and explain its marker on the timeline.
8. Adjust the minimap window and visibility level to demonstrate timeline navigation.
9. Refresh the page and confirm the single-page application loads normally.
10. Open `/health/ready` in a separate tab and show the healthy database record count.

Suggested introduction:

> This client demo presents a frozen, validated snapshot of 279 Australian COVID-19 vaccine mandate records. The browser interface, API, and read-only SQLite dataset are deployed together as one reproducible container.
